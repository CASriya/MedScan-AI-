# 🩺 MedScan AI

An AI-powered Smart Lab Report Analyzer that helps users understand blood test reports through interactive dashboards and health insights.

## Features

- Health Dashboard
- Risk Analysis
- AI Recommendations
- OCR Report Upload
- PDF Export
- Interactive Charts
- Doctor Suggestions
- Chatbot
- Dark/Light Theme
- Multi-language Support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- jsPDF

## How to Run

1. Download the project.
2. Open `index.html` in a web browser.
3. Enter sample lab values.
4. View health analysis.
